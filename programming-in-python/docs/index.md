# Welcome in the Course Programming in Python

This site contains the course material for the course Programming in Python taught at VIVES University of Applied Sciences, campus Kortrijk. 

The site contains the course, but the exercises, exercise solutions, assignments, ... can be found in the online learning platform Toledo.

# Welkom in the cursus Programming in Python

Deze site bevat het cursusmateriaal voor de cursus Programming in Python, die aan de VIVES hogeschool gedoceerd wordt. 

Deze site bevat de cursus zelf, maar de oefeningen, oplossingen van oefeningen, opdrachten, ... vind je op het leerplatform Toledo.
